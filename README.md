# راهنمای بالا آوردن داشبوردها روی GitHub Pages (مجانی)

## چرا GitHub Pages و نه Vercel؟
- Vercel بازدیدکننده‌های داخل ایران را بلاک می‌کند (تحریم — خطای 403) و دامنه‌اش هم اغلب فیلتر است؛ یعنی پدرتان بدون فیلترشکن نمی‌تواند باز کند.
- GitHub Pages (`github.io`) از داخل ایران بدون فیلترشکن باز می‌شود، رایگان است و لینک همیشه ثابت می‌ماند.

## مرحلهٔ ۱ — ساخت مخزن (فقط بار اول)
1. وارد github.com شوید (اگر اکانت ندارید، رایگان بسازید).
2. دکمهٔ **New repository** را بزنید.
3. اسم بگذارید مثلاً `dashboard` — حتماً **Public** باشد — بعد **Create repository**.

## مرحلهٔ ۲ — آپلود فایل‌ها
1. در صفحهٔ مخزن روی **uploading an existing file** (یا Add file → Upload files) کلیک کنید.
2. دو فایل همین پوشه را بکشید و رها کنید:
   - `index.html`  (داشبورد چهارکادره — مس/نقره/طلا/سکه)
   - `silver.html` (داشبورد کامل نقره)
3. پایین صفحه **Commit changes** را بزنید.

## مرحلهٔ ۳ — روشن کردن Pages (فقط بار اول)
1. در مخزن: **Settings → Pages**
2. قسمت Build and deployment → Source روی **Deploy from a branch**
3. Branch را روی **main** و پوشه را روی **/ (root)** بگذارید → **Save**
4. یکی دو دقیقه صبر کنید؛ لینک شما آماده است:

   `https://نام‌کاربری.github.io/dashboard/`

همین لینک را یک بار برای پدرتان بفرستید — داشبورد چهارکادره باز می‌شود و دکمهٔ رفتن به داشبورد نقره هم بالایش هست.

## آپدیت‌های بعدی (هر بار)
1. فایل جدیدی که من می‌دهم را با همان نام (`index.html` یا `silver.html`) در مخزن آپلود کنید (Add file → Upload files → Commit).
2. تمام! لینک پدرتان همان است و بعد از یکی دو دقیقه نسخهٔ جدید را می‌بیند.
   (اگر نسخهٔ قدیمی نشان داد، یک‌بار صفحه را با Ctrl+F5 تازه کند.)

## نکته‌ها
- قیمت‌ها را خود صفحه مستقیم از TGJU می‌گیرد؛ آپلود جدید فقط وقتی لازم است که قابلیت جدیدی اضافه شود.
- شمارهٔ نسخه زیر عنوان هر داشبورد نوشته شده تا مطمئن شوید نسخهٔ جدید بالا آمده.
- کاتد مس از iranzayeat.com می‌آید که فقط از داخل ایران زنده جواب می‌دهد؛ برای شما (خارج از ایران) ممکن است «آخرین قیمت ذخیره‌شده» نمایش داده شود — برای پدرتان در ایران شانس زنده‌بودنش بیشتر است.
