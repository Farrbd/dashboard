# راهنمای بالا آوردن داشبوردها روی GitHub Pages (مجانی) + تبدیل به اپلیکیشن اندروید

## تازه: تم «رز روی مشکی» (نسخهٔ ۱۷)
- پالت جدید: مشکی خالص `#000000` · رز کریمسون `#CB2957` · خاکستریهای روشن `#DDDDDD` / `#EEEEEE`
- صعود/خوب = سفید درخشان · نزول/هشدار/حباب = خانوادهٔ رز · خنثی = خاکستری
- کش مرورگر تازه شد (sw v2)؛ اگر رنگهای قدیمی دیدید یک بار Ctrl+F5.

## چرا GitHub Pages و نه Vercel؟
- Vercel بازدیدکننده‌های داخل ایران را بلاک می‌کند (تحریم — خطای 403) و دامنه‌اش هم اغلب فیلتر است؛ یعنی پدرتان بدون فیلترشکن نمی‌تواند باز کند.
- GitHub Pages (`github.io`) از داخل ایران بدون فیلترشکن باز می‌شود، رایگان است و لینک همیشه ثابت می‌ماند.
- **این نسخه «اپلیکیشن قابل نصب» (PWA) است**: بعد از بالا آمدن، می‌شود آن را مثل یک اپ واقعی با آیکون روی گوشی اندروید/آیفون نصب کرد — تمام‌صفحه باز می‌شود و حتی بدون اینترنت هم آخرین قیمت‌ها را نشان می‌دهد.

## مرحلهٔ ۱ — ساخت مخزن (فقط بار اول)
1. وارد github.com شوید (اگر اکانت ندارید، رایگان بسازید).
2. دکمهٔ **New repository** را بزنید.
3. اسم بگذارید مثلاً `dashboard` — حتماً **Public** باشد — بعد **Create repository**.

## مرحلهٔ ۲ — آپلود فایل‌ها
1. در صفحهٔ مخزن روی **uploading an existing file** (یا Add file → Upload files) کلیک کنید.
2. همهٔ فایل‌های همین پوشه را با هم بکشید و رها کنید (درگ کردن کل پوشه هم کار می‌کند):
   - `index.html`  (داشبورد چهارکادره — مس/نقره/طلا/سکه)
   - `silver.html` (داشبورد کامل نقره)
   - `gold.html`  (داشبورد کامل طلا — همهٔ مدل‌ها)
   - `coin.html`  (داشبورد کامل سکه)
   - `copper.html`(داشبورد کامل مس)
   - `fonts.css`
   - `metals-bootstrap.js`
   - `manifest.json` ⚠️ (برای نصب اپ لازم است)
   - `sw.js` ⚠️ (برای آفلاین و نصب اپ لازم است)
   - `pwa.js` ⚠️ (دکمهٔ «نصب اپ»)
   - `icons/` ⚠️ (پوشهٔ آیکون‌ها — ۴ فایل png)
3. پایین صفحه **Commit changes** را بزنید.

## مرحلهٔ ۳ — روشن کردن Pages (فقط بار اول)
1. در مخزن: **Settings → Pages**
2. قسمت Build and deployment → Source روی **Deploy from a branch**
3. Branch را روی **main** و پوشه را روی **/ (root)** بگذارید → **Save**
4. یکی دو دقیقه صبر کنید؛ لینک شما آماده است:

   `https://نام‌کاربری.github.io/dashboard/`

## مرحلهٔ ۴ — نصب اپ روی گوشی اندروید ⭐
1. لینک بالا را در **Chrome** گوشی پدرتان باز کنید.
2. دکمهٔ **«📲 نصب اپ»** که بالای داشبورد آمده را بزنید و تأیید کنید.
   (اگر دکمه نبود: منوی **⋮** → **افزودن به صفحهٔ اصلی** / **نصب برنامه**)
3. تمام! آیکون گیج-شمش روی صفحهٔ گوشی است؛ با لمسش اپ تمام‌صفحه باز می‌شود.
   - ✅ بدون اینترنت هم باز می‌شود (آخرین دادهٔ ذخیره‌شده).
   - ✅ روی لینک مخفی/لجنبی هم مثل اپ رفتار می‌کند.
   - ✅ لمس طولانی آیکون: میان‌بر مستقیم به صفحهٔ مس / نقره / طلا / سکه.

### آیفون؟
سافاری → دکمهٔ اشتراک **⬆** → **Add to Home Screen**.

### می‌خواهید فایل APK جدا (نه از داخل سایت) داشته باشید؟
سایت **pwabuilder.com** (رایگان، از مایکروسافت) — همان لینک GitHub Pages را بدهید و از آن APK بگیرید،
ولی راه راحت‌تر و بدون دردسر همان نصب از داخل Chrome است؛ برای پدرتان همین کافی است.

## آپدیت‌های بعدی (هر بار)
1. فایل‌های جدیدی که من می‌دهم را با همان نام‌ها در مخزن آپلود کنید (Add file → Upload files → Commit).
2. تمام! لینک پدرتان همان است؛ اپ هم خودش نسخهٔ جدید را می‌گیرد (یک‌بار بستن و باز کردن کافی است).
